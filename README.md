# 🎬 BrainFlix – A YouTube-Style Video Player App

BrainFlix is a sleek and functional video player application inspired by YouTube, built with **React**, **core JavaScript concepts**, and styled using **SCSS with BEM**. It supports video playback, comments, suggested videos, and more — perfect for practicing real-world front-end development skills.


## 🚀 Live Demo

🔗 [Check out the live app](https://your-live-link.com) 


## ✨ Features

- ▶️ Play and switch between videos
- 💬 Add and view comments under each video
- 📺 Suggested videos list
- 🧠 Built using **React hooks** (`useState`, `useEffect`)
- 💅 Styled with **SCSS** using **BEM naming convention**
- ⚡ Dynamic data rendering using **JavaScript array methods**
- 📱 Fully responsive for desktop and mobile views


## 🛠️ Tech Stack

- **React** (functional components + hooks)
- **JavaScript (ES6+)**
- **HTML5**
- **SCSS (Sass)** + **BEM**
- **React Router** (for video page navigation)
- **Fake JSON data** to simulate backend/API
